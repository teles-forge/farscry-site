import { Steps, Tabs, TabItem } from '@astrojs/starlight/components';

<Steps>

1. **Install farscry**

   <Tabs syncKey="pkg">
     <TabItem label="npm">
     ```bash
     npm install -g farscry
     ```
     </TabItem>
     <TabItem label="pip">
     ```bash
     pip install farscry
     ```
     </TabItem>
     <TabItem label="Homebrew">
     ```bash
     brew install teles-forge/tap/farscry
     ```
     </TabItem>
     <TabItem label="cargo">
     ```bash
     cargo install farscry
     ```
     </TabItem>
     <TabItem label="curl">
     ```bash
     curl -fsSL https://farscry.dev/install | sh
     ```
     </TabItem>
   </Tabs>

2. **Wire up your agent**

   ```bash
   farscry setup
   ```

   Detects Claude Code, Cursor, Windsurf, and Zed automatically. Shows the config snippet to paste, farscry never modifies your files.

3. **Extract from a screenshot**

   ```bash
   farscry screenshot.png
   ```

   Output:

   ```
   === farscry visual context ===
   screen_type: config
   ---

   [top-left]   heading  "Payment Settings"
   [mid-left]   label    "Max Value:"
   [mid-center] input    value="1500"       editable:true   at (200,120)
   [mid-right]  button   "Save Changes"     enabled:true    at (400,300)
   [bottom]     error    "Value must be ≤ 10000"

   affordances:
     click → "Save Changes"   at (400,300)
     type  → "Max Value"      at (200,120)   current:"1500"
   ```

4. **Diff two screenshots**

   ```bash
   farscry diff before.png after.png
   ```

   Output:

   ```
   === farscry diff ===
   from: phash:8f4a2c3d
   to:   phash:3d9b1e7a
   ---

   + appeared:
     "error_banner"  "Card declined"   at (0,48)

   ~ changed:
     "Submit"   enabled:true → enabled:false

   - removed:
     spinner   at (450,200)

   — 38ms · 3 of 12 elements changed
   ```

5. **Pipe to an agent**

   ```bash
   farscry screenshot.png | claude "fix this"
   farscry --from-clipboard | devin "fix this"
   farscry screen.png | codex "what broke"
   ```

   farscry writes to stdout. Pipe anywhere.

</Steps>

## Common flags

| Flag | Description |
|---|---|
| `--json` | JSON output instead of VASP text |
| `--affordances` | Show only interactive elements |
| `--context` | One-line `agent_context` summary |
| `--lang por` | Explicit language (default: auto-detect) |
| `-v` | Verbose, show processing steps |

## Known limitations in v0.1.0

:::caution
farscry is optimized for developer tool screenshots, terminals, config panels, web UIs, IDE output.
:::

| Scenario | Status | Notes |
|---|---|---|
| Text-heavy UIs (terminal, config, forms) | Works well | Core use case |
| Icon-only toolbars | Partial | Buttons without text labels are missed |
| Charts, graphs, images | Not supported | OCR extracts no structured data |
| `--from-clipboard` on Linux | Requires `xclip` | `apt install xclip` |
| Windows | Untested in v0.1.0 | Binary ships, not CI-validated |
